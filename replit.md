# Photo Cards Gallery

This is a static website built with plain HTML and CSS. It does not use a framework or build step.

## Run

Use the **Run** button. Replit serves the project from `index.html` on port 5000 with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

`photocards.html` is also available directly at `/photocards.html`.
